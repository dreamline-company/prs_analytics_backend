# МРП: межремонтный период и ЧРФ

Расчёт показателей по методике заказчика (форма ИСУ KMG-F-2429.1-10 «Приложение к
методике расчёта МРП и наработки на отказ») и по отдельной скважине.

## Эндпоинты

| Эндпоинт | Параметры | Что |
|---|---|---|
| `GET /kpi/v1/mrp/summary` | `ngdu_id`, `oil_field_id` (как в сводке НГДУ), `end_month` (`YYYY-MM`, по умолчанию прошлый месяц), `months` (12), `crf_min_repairs` (3) | МРП с ГТМ и без ГТМ за скользящий период по НГДУ / месторождениям / способам добычи + ЧРФ и градация |
| `GET /kpi/v1/mrp/dynamics` | `ngdu_id`, `oil_field_id`, `end_month`, `points` (12), `window_months` (12) | Динамика по месяцам: МРП месяца и МРП скользящего периода (с ГТМ и без) — как строки «Текущий месяц» и «Скользящий год» формы КМГ |
| `GET /repairs/v1/mrp/by-well` | `well_id` | МРП скважины: до и после каждого ремонта, индикатор качества, средний МРП, готовая интерпретация |

ИИ-ассистент получил инструмент `get_well_mrp` (`ai_assistant/ai/chat_assistant/tools.py`):
считает код, модель пересказывает готовую интерпретацию.

## Формулы (форма КМГ)

```
отказы        = ремонты − ГТМ                (минус «по технической причине» — в данных нет)
МРП с ГТМ     = время работы действующего фонда ÷ число ремонтов
МРП без ГТМ   = время работы действующего фонда ÷ число отказов
```

- **Действующий фонд месяца** — скважины, у которых на 1-е число месяца действует
  технологический режим с плановым дебитом жидкости > 0 (`telemetry_tech_regime`).
  Определение восстановлено по файлам заказчика (форма KMG-F-2429.1-10, Кайнар,
  2025–2026): фонд совпадает до 1%, а не по статусу «в работе» — по статусам фонд
  выходил на ~20% больше. Скважина вне фонда месяца в этом месяце не учитывается
  ни во времени работы, ни в числе ремонтов.
- **Время работы** — интервалы статуса «в работе» (`WRK`, `PEXP`) из
  `wells_well_status` у скважин фонда месяца, за вычетом времени ремонтов. Статусы
  и ремонты записаны в местном времени, перевод из UTC не нужен. Расхождение с
  файлами заказчика по Кайнару около +1%.
- **Среднедействующий фонд** — среднее по месяцам окна число скважин фонда;
  **действующий фонд на конец окна** — скважины фонда последнего месяца.
- **Число ремонтов** — записи ремонтов, начатые в окне у скважин, входящих в фонд
  месяца начала (удалённые в ABAI не берутся). Записи встык (разрыв меньше суток)
  в расчёте по скважине считаются одним ремонтом. По Кайнару (янв 2025 – авг 2026)
  934 против 943 у заказчика.
- **ГТМ** — `apps/repairs/services/repair_classifier.py`; перечень подтверждён геологом
  заказчика: промывка и очистка забоя (мех. примеси), подготовка к ГИС и ГРП, ГРП,
  ликвидация скважин, консервация, расконсервация и ввод из консервации, ввод из
  бурения (освоение). Решает вид работ (`repairs_repair_type.name_ru`); текст ремонта —
  только если вида нет. Смена способа эксплуатации (ЭВН ↔ ШГН) — обычный ремонт, не
  ГТМ. По Кайнару (скользящий год до авг 2026): ГТМ 204 против 207 в отчёте заказчика.
  Признак «по технической причине» в данных ABAI отсутствует (у заказчика ~25 ремонтов
  в год по Кайнару) — из отказов не вычитается, поэтому МРП без ГТМ чуть занижен.
- **ЧРФ** — скважины с `crf_min_repairs` и более ремонтами **без ГТМ** за окно;
  доля — от действующего фонда на конец окна. Отличается от флага
  `is_frequent_repair` в матрице скважин (`FREQUENT_REPAIR_THRESHOLD`, все ремонты
  за 365 дней, строго больше порога).

## Динамика по месяцам

Для каждого из `points` месяцев считаются показатели самого месяца и скользящего
периода из `window_months` месяцев, заканчивающегося им. Последняя точка совпадает с
`/kpi/v1/mrp/summary` за то же окно (проверено тестом). Месяц без ремонтов (или без
отказов) даёт `null`, а не 0 сут: месячные значения сильно скачут — в месяц бывает 1–3
отказа, надёжен скользящий ряд. Расчёт ряда на 933 скважинах — менее секунды.

## МРП скважины и индикатор качества

МРП до ремонта — от конца предыдущего ремонта до начала этого; после — от конца этого
до начала следующего. `verdict`:

- `worse` — МРП после ремонта меньше, чем был до него (ремонт неэффективный);
- `better` — не меньше;
- `watching` — следующего ремонта ещё нет, а скважина работает меньше прежнего МРП;
- `unknown` — нет данных для сравнения.

Любое сокращение считается ухудшением — порога значимости в методике нет.

## Ограничения

- Признака «по технической причине» из ABAI в данных нет — отказы завышены.
- ГТМ определяются по тексту, поэтому ЧРФ и «МРП без ГТМ» — оценка. Точный расчёт
  возможен, когда у вида работ появится признак ГТМ (решение заказчика).
- Не отфильтрованы ремонты по `abai_repair_type_id` (4 «прочие простои», 5 «наземный
  ремонт»): в проверочных расчётах по Кайнармунайгазу числа близки к отчётам
  заказчика и без этого.

## Проверка

Расчёт сверен на данных Кайнармунайгаза (окно 10.2025–09.2026) с отчётами заказчика:
МРП с ГТМ 301 сут против 311,7 в их форме; без ГТМ 479 против 536; ЧРФ 39 скважин против 30.
Расхождение объясняется приблизительной классификацией ГТМ и отсутствием признака
«по технической причине».
